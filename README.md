# Sterling
Voice agent for Android. Orb overlay, tap to talk, Needle 3 (Cactus) routes speech to tools.
1. Create a GitHub repo, push this folder.
2. Actions tab -> "Build Sterling" -> download the `sterling-apk` artifact.
3. Install, grant the 4 permissions in the app, tap Start Sterling.
Needle 3 hookup: see `needle()` in Brain.kt. Until wired, a simple rule router handles commands.
